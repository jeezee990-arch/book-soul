## 写作

> 路径：左侧导航「写作」/（默认首页）
> 用途：写章节 / 流式生成 / 选区重写 / 质检 / 人物 / 大纲 / 版本

三栏布局：

```
┌──────────────┬─────────────────────────────┬──────────────┐
│  章节树       │  纸感编辑区（Tiptap）          │  上下文面板   │
│   244px      │      固定浅色纸面              │    332px     │
│              │                             │              │
│  + 新建章节   │  粗体/斜体/标题/列表/引用/撤销  │  6 个 Tab    │
│  章节列表     │  编辑区下方有「重写」「质检」   │              │
│              │  两个快捷按钮                   │              │
└──────────────┴─────────────────────────────┴──────────────┘
```

**顶部**是全局上下文栏：作品切换器（**全应用唯一**）、面包屑、模型状态灯。

### 选作品 + 选章节

- 顶部作品切换器选作品 —— 切换一次，全应用生效，切页面不丢
- 左侧章节树点章节；点「+ 新建章节」填标题和大纲

### 右栏 6 个 Tab

| Tab | 做什么 |
|---|---|
| **生成** | 流式生成正文。可填本章要点、目标字数 |
| **重写** | 选段重写。**必须先在正文里选中一段**，没选区时按钮禁用并提示 |
| **质检** | 5 维度并行评分 + 一键重写闭环 |
| **人物** | 当前作品的人物卡列表（生成正文时只注入「本章出场」的人物卡） |
| **大纲** | 结构化渲染 + 可编辑 + 一键把大纲章节拆成正文章节 |
| **版本** | 版本历史 + diff 对比 + 回滚 |

### 写章节

- 编辑区是**固定的浅色纸面**（`#faf8f3`），不随主题切换 —— 长时间写作不刺眼
- 编辑区下方常驻显示上下文来源：`人物卡 · 最近 3 章摘要 · 上一章尾部`
- 自动保存到当前版本的「草稿」（**不是**新版本；只有显式生成 / 重写 / 回滚才入版本库）

### 流式生成正文

1. 右栏切到「生成」Tab
2. 填本章要点（可选）、目标字数
3. 点「生成正文」→ 正文一个字一个字冒出来
4. 模型思考期会显示「模型思考中…」面板（**思考内容不会被丢弃**，但会净身成纯中文）
5. 完成后自动写一条 `llm_generate` 版本

> **落库的是编辑器全文，不是流式累积量** —— 生成是追加、重写是替换选区，
> 累积量都不是完整正文，直接存会抹掉章节原有内容。

### 选段重写

1. 在正文里**选中一段文字**
2. 右栏「重写」Tab 会显示选区，填重写要求（如「更紧凑 / 换对话风格 / 补心理活动」）
3. 点「重写选段」→ AI 逐字替换
4. 完成后自动写一条 `rewrite` 版本，原文保留在版本历史里，随时可回滚

### 质检（5 维度并行）

1. 右栏切到「质检」Tab
2. 点「开始检测」（需要章节有正文）
3. 等 5-30s（5 个维度的 LLM 调用是**并行**的）
4. 看报告：总分环 + 雷达图 + 各维度 issues

| 维度 | 关注 |
|---|---|
| 文笔 | 流畅度 / 修辞 / 用词 / 画面感 |
| 逻辑 | 情节自洽 / 设定一致 / 时间线 / 动机 |
| 节奏 | 起承转合 / 详略 / 张弛 / 钩子 |
| 一致性 | 人物性格 / 对话 / 关系 / 能力（基于人物卡） |
| 题材合规 | 世界观 / 俗套 / 越界（基于题材常识库） |

**闭环**：每条问题下面直接点「重写这段」→ 带着问题描述跳到「重写」Tab 并预填指令。
问题不留 in 报告，直接被修掉。

### 版本控制

- 右栏「版本」Tab：版本列表（按时间倒序）+ 触发原因标签（生成 / 重写 / 手动保存 / 回滚）
- 选一个版本 → 显示 unified diff 或 split view
- 点「回滚到该版本」：**保留原历史，生成一条新的 rollback 版本**（parent = 当前最新），审计链完整

## 开新书

> 路径：左侧导航「开新书」/ `/new`
> 用途：从一个灵感种子开始，三步得到「作品 + 大纲 + 人物卡」

顶部有进度条，三步依次是：**种子 → 剧情 → 大纲与人物**。

### 第 1 步 · 种子

- 选**题材**（修仙 / 都市 / 悬疑 / 言情）—— 决定词库、题材常识与质检标准
- 挑**关键词**（从种子库点选，或直接输入后回车加入）
- 顺带可以「种子库管理」：按板块编辑词条，改完立刻刷新候选词

### 第 2 步 · 剧情

- 点「生成 3 个剧情」→ **三个版本同时流式出字**（不是等全部生成完再一起出来）
- 每个版本显示：AI 的思考过程 + 正文 + 命中了几个种子词
- 选中一个作为下一步基准；选错了可以「← 换一条剧情」回来重选

### 第 3 步 · 大纲与人物

- 先选「接下来生成哪种大纲」：**完整大纲**（一次性给出全部分卷与章节，适合短篇）/ **半开放大纲**（只生成前期，保留悬念）
- 再设**大纲规模**（总章数 / 每卷章数 / 每章字数）—— 这是硬指标，会写进 prompt
- 可填对大纲或人物的特别要求
- 点生成 → 先出**作品骨架**，再并行补各卷章节详情，同时生成**人物卡**
- 完成后提示「大纲与人物卡都已入库，可以直接开始写第一章」

> 剧情、大纲、人物卡都是**流式**的。单个版本失败不影响其它版本 —— 失败的那张卡会单独标红。

## 素材库

> 路径：左侧导航「素材库」/ `/library`
> 三 Tab：作品 / 灵感 / 导入

### 作品

全部作品列表，状态标签：草稿 / 连载中 / 已完成 / 已导入。

点进详情有 3 个 Tab：**章节 / 人物卡 / 大纲**，可以导出（Markdown / HTML / Word .docx）。

「新建作品」建的是**空壳** —— 之后去「开新书」让 AI 生成大纲与人物卡，或者直接进写作页手写。

### 灵感

所有灵感（关键词 / 剧情 / 片段 / 画面 / 备注）。卡片支持右键菜单（重命名 / 删除等）。

点开详情可以看到关联作品的人物卡 / 大纲 / 章节。灵感是**独立**的 —— 删掉关联作品，灵感会保留，只是脱离关联。

### 导入（本地扫描）

1. 输入本地小说目录（如 `D:\novels\凡人修仙传`）
2. 点「开始扫描」：自动检测含章节标记的 .md 文件
3. 展开看每个检测到的小说 + 章节预览
4. 点「导入」：自动建作品 + 章节（标记为已导入，只读）

## 设置

> 路径：左侧导航「设置」/ `/settings`
> 四个分区：LLM 与密钥 / 数据与备份 / AI 增强 / 外观

### LLM 与密钥

- provider 列表：mimo（默认，国内直连免 VPN）/ minimax / OpenAI / Ollama（本地）
- 每个 provider 显示**可用 / 不可用**状态（探测带 API Key 鉴权，能区分「服务挂了」和「key 错了」）
- 填 API Key → 保存。存储优先级：**环境变量 > DPAPI 加密文件 > 系统 Keyring**，明文永不落盘
- 「刷新列表」按钮会绕过缓存强制重新拉模型清单
- 场景路由在 `config/llm.yaml` 里配（哪个场景用哪个 provider）

### 数据与备份

- **导出备份**：把整个数据目录打包成 .zip
- **从备份恢复**：覆盖当前数据（恢复后需要重启应用）
- 章节字数硬限 1k-8k、context_window 必须 ≥ 32k 才能生成章节 —— 这些限制由配置驱动，不可绕过

### AI 增强

内置 12 个 Skill 工具（原「Skills」页面已降级到这里）：

| Skill | 用途 | LLM |
|-------|------|-----|
| word_counter | 中英文混合字数 | ✗ |
| sensitive_word | 敏感词检测 | ✗ |
| chapter_summarizer | 章节粗略摘要 | ✗ |
| character_extractor | 启发式角色抽取 | ✗ |
| plot_analyzer | 关键事件关键词密度 | ✗ |
| web_search | 网络搜索（占位） | ✗ |
| read_local_file | 读 .md / .txt 文件 | ✗ |
| consistency_checker | 别名一致性 | ✗ |
| style_analyzer | 句长 / 感叹号 / 对话占比 | ✗ |
| pacing_visualizer | 段长分布（节奏曲线） | ✗ |
| outline_structurer | 大纲结构化 | ✗ |
| genre_classifier | 题材分类 | ✗ |

也可以放自己的 Skill 到 `config/skills/`（开发态）或数据目录（打包态）。

### 外观

- 深色 / 浅色主题，即时切换
- 纸面是否跟随主题（默认**不跟随** —— 编辑区固定浅色纸面更护眼）

## 常见问题

**Q: 流式生成很慢？**
A: 先看顶栏模型状态灯是不是「可用」。**慢在模型，不在代码** —— 代码侧每个 token 只增加约 0.5ms。
推理模型（如 MiniMax-M3）的思考期可能好几秒，这段时间会显示「模型思考中…」，不是卡死。

**Q: 三个剧情版本不是同时出来的？**
A: 内容是实时透传的（谁先回谁先显示），只有「这个版本好了」的完成提示按下标保序。
如果某张卡一直转圈但别的已完成，那张卡对应的版本可能失败了 —— 看它有没有标红报错。

**Q: 章节生成字数不到 1k？**
A: 提示词或大纲太短。章节字数硬限是 1k-8k，可在 `config/llm.yaml` 的 `chapter_limits` 调整。

**Q: 写作页编辑器很卡？**
A: 长章节下 Tiptap 频繁插入是 O(n)。刷新页面或减少单章长度。

**Q: 生成的内容不是我写的那部分，被覆盖了？**
A: 保存取的是编辑器全文而不是流式累积量。生成是**追加**，重写是**替换选区** ——
被重写的原文在版本历史里，随时可回滚。

**Q: 备份恢复后页面没刷新？**
A: 重启应用（数据库连接池已建立，需要重连）。

**Q: Word 导出失败？**
A: 后端需要 `python-docx`。运行 `uv add python-docx` 后重启。
