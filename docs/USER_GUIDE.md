## 灵感园

> 路径：左侧导航"灵感园"
> 用途：3 步流程创建一部新作品

**流程**：

1. **选题材**：点击题材卡片（修仙 / 都市 / 悬疑 / 言情）
2. **选灵感词**：从词库挑 5+ 个关键词；点"生成剧情"
3. **选剧情**：从 3 个 AI 生成的剧情版本里选一个
4. **生成大纲**：基于剧情自动生成完整大纲（含卷 + 章 + 关键事件）
5. **生成人物卡**：基于大纲自动提取人物 + 生成人物卡
6. **保存**：自动创建 Novel + 全部入库

## 创作

> 路径：左侧导航"创作"
> 用途：写章节 / 流式生成 / 选区重写 / 版本控制

### 选作品 + 选章节

- 顶部"作品"下拉选作品
- 左侧章节列表
- 点"+ 新建章节"填标题和大纲

### 写章节

- 右侧 Tiptap 富文本编辑器：粗体 / 斜体 / 标题 / 列表 / 引用 / 撤销
- 自动保存到当前版本的"草稿"（不是新版本；显式"流式生成/重写/回滚"才入版本库）

### 流式生成章节

1. 点右下"流式生成"
2. 输入额外要求（可选）："重点写战斗 / 心理 / 对话…"
3. 看到字一个个蹦出来（流式）
4. 完成后自动写一条 `llm_generate` 版本

### 选段重写

1. 在编辑器里**选中一段文字**
2. 点"选段重写"
3. 输入要求（"更紧凑 / 换对话风格"）
4. 看到 AI 逐字替换
5. 完成后自动写一条 `rewrite` 版本

### 版本控制

- 点章节卡片右上"版本历史"
- 左边版本列表（按时间倒序）+ 触发原因标签
- 选一个版本 → 右侧显示 unified diff 或 split view（react-diff-viewer-continued）
- 点"回滚到该版本"：保留原历史，生成一条 `rollback` 新版本（parent=当前最新）

## 质检

> 路径：左侧导航"质检"
> 用途：5 维度并行评分

### 步骤

1. 选作品 → 选章节（需有正文）
2. 点"开始检测"
3. 等 5-30s（5 维度 LLM 并行）
4. 看报告：
   - **总分**：0-10 圆环
   - **雷达图**：5 维度分数分布
   - **维度详情**：可展开看 issues + 整体建议

### 5 维度

| 维度 | 关注 |
|------|------|
| 文笔 | 流畅度 / 修辞 / 用词 / 画面感 |
| 逻辑 | 情节自洽 / 设定一致 / 时间线 / 动机 |
| 节奏 | 起承转合 / 详略 / 张弛 / 钩子 |
| 一致性 | 人物性格 / 对话 / 关系 / 能力（基于人物卡）|
| 题材合规 | 世界观 / 俗套 / 越界（基于常识库）|

## 仓库

> 路径：左侧导航"作品库"
> 4 tab：作品 / 藏书馆 / 本地扫描 / 灵感库

### 作品

全部 novel 列表。每条：
- 导出（md / html / docx）
- 进入详情（人物卡 + 章节 + 版本 + 导出）

### 藏书馆

只显示有正文的作品（word_count > 0）。适合"已写完想阅读"。

### 本地扫描

1. 输入本地小说目录（如 `D:\novels\凡人修仙传`）
2. 点"开始扫描"：自动检测 ≥3 个含章节标记的 .md 文件的目录
3. 展开看每个检测到的小说 + 章节预览
4. 点"导入"：自动建 novel + chapters（标记 read_only + imported）

### 灵感库

所有 inspiration（关键词 / 剧情 / 片段 / 画面 / 备注）。点卡片看详情：
- 灵感内容
- 关联作品的人物卡 / 大纲 / 章节
- 导出该作品

## Skills

> 路径：左侧导航"Skills"
> 用途：12 个文本处理工具，无需 LLM（除 web_search）

### 12 个内置 skill

| Skill | 用途 | LLM |
|-------|------|-----|
| word_counter | 中英文混合字数 | ✗ |
| sensitive_word | 敏感词检测 | ✗ |
| chapter_summarizer | 章节粗略摘要 | ✗ |
| character_extractor | 启发式角色抽取 | ✗ |
| plot_analyzer | 关键事件关键词密度 | ✗ |
| web_search | 网络搜索（占位）| ✗ |
| read_local_file | 读 .md / .txt 文件 | ✗ |
| consistency_checker | 别名一致性 | ✗ |
| style_analyzer | 句长 / 感叹号 / 对话占比 | ✗ |
| pacing_visualizer | 段长分布（节奏曲线）| ✗ |
| outline_structurer | 大纲结构化 | ✗ |
| genre_classifier | 题材分类 | ✗ |

### 用法

1. 点 skill 卡片"使用"
2. 输入字段（按 schema）
3. 点"执行" → 看 JSON 结果

## 设置

> 路径：左侧导航"设置"

### LLM Provider

- mimo（默认，国内免 VPN）
- minimax（备用，需 VPN）
- OpenAI（备用）
- Ollama（本地）

填 API Key → 点"保存"。

### 主题

深色 / 浅色。即时切换。

### 数据目录

`BOOK_SOUL_DATA_DIR` 环境变量决定（默认 `~/Documents/BookSoul`）。修改后重启服务。

### 加密

Phase 2 占位。开启后敏感数据加密存储；当前默认关闭。

### 备份 / 恢复

- 导出备份：把 data_dir 打包为 .zip
- 从 .zip 恢复：覆盖当前数据；恢复后请重启 Tauri

## 常见问题

**Q: 流式生成很慢？**
A: 检查 LLM provider；mimo 国内节点首字延迟 5-15s。批量 LLM 调用是并行的（5 维度质检），但每个维度是串行 token 输出。

**Q: 章节生成字数不到 1k？**
A: 提示词或大纲太短；prompt 中明确要求"不达下限不收尾"。

**Q: 创作页编辑器很卡？**
A: 长章节下 Tiptap 频繁插入会 O(n)；刷新页面或减少流式更新频率（v1.1 优化）。

**Q: Word 导出失败？**
A: 后端需 `python-docx`；运行 `uv add python-docx` 重启。

**Q: 备份恢复后页面没刷新？**
A: 重启 Tauri 桌面应用。
